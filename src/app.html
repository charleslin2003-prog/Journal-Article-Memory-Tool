雲端同步
文獻庫存在你雲端硬碟的「論憶」資料夾（lunyi-library.json）。其他裝置連結同一個 Google 帳號即可同步。需要先在上方連結 Google 帳號。
把文獻庫存在你 GitHub 帳號的私人 Gist，多台裝置填同一組權杖與 Gist ID 即可同步。權杖到 GitHub → Settings → Developer settings → Personal access tokens 建立，只需要 Gists 讀寫權限。第一次上傳會自動建立 Gist。
