雲端同步
文獻庫存在你雲端硬碟的「論憶」資料夾（lunyi-library.json）。其他電腦用同一個 Google 帳號登入即可同步。需要先在「我的帳號」用 Google 登入。
把文獻庫存在你 GitHub 帳號的私人 Gist，多台電腦填同一組權杖與 Gist ID 即可同步。權杖到 GitHub → Settings → Developer settings → Personal access tokens 建立，只需要 Gists 讀寫權限。第一次上傳會自動建立 Gist。
自動同步開啟時，開啟網站會先下載合併，之後每次變更約 3 秒後自動上傳。{{ syncStatus }}
